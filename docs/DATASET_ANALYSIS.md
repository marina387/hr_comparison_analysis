## 3. Результаты анализа датасетов

### Hugging Face (resume-score-details)

| Показатель | macro_scores_avg | micro_scores_avg |
|------------|------------------|------------------|
| **Количество** | 854 | 854 |
| **Среднее** | 3.2 | 3.1 |
| **Минимум** | 1.5 | 1.2 |
| **Максимум** | 9.55 | 9.85 |
| **Стандартное отклонение** | 0.9 | 1.0 |

**Особенность:** максимальная микро-оценка (9.85) превышает макро-оценку (9.55). Кандидат может иметь выдающиеся навыки при среднем опыте.

**Регрессия:**
micro_scores_avg = 0.45 + 0.84 * macro_scores_avg
R² = 0.65

### Resume Dataset (Kaggle)
- **Размер:** 9,544 строки, 35 колонок
- **Ключевые поля:** `skills`, `education`, `work_experience`, `certifications`
- **Применение:** обучение эмбеддингов, извлечение навыков

### hh.ru + SuperJob
- **Размер:** 171,000+ строк, 30+ колонок
- **Ключевые поля:** `name`, `description`, `salary_from`, `salary_to`, `region_name`, `hard_skills`, `soft_skills`
- **Применение:** русскоязычная демонстрация, анализ рынка зарплат
